# Update Readme

Use this skill anytime a code change adds or modifies a feature, route, or dependency.

## Workflow
1. Inspect the code and identify what changed (feature behavior, routes/endpoints, packages/libraries).
2. Open `README.md` and keep the existing structure and formatting style if the file already exists.
3. Update or add content in these sections (and keep them in this order):
   - Project Overview
   - Features
   - Setup
   - Dependencies
4. Document:
   - A clear description of what changed.
   - How to use the new feature or route (include example path/usage when relevant).
   - Any new dependencies that were added and why they are needed.
5. Keep updates concise, accurate, and consistent with the rest of the README.

## Output Checklist
- README reflects all new features/routes/dependencies from the current change.
- Section order remains: Project Overview, Features, Setup, Dependencies.
- Existing README formatting conventions are preserved.
